Git

  • git add добавляет изменения из рабочего каталога в индекс (staging area / индекс) — промежуточную зону перед коммитом. Это готовит файлы к сохранению в истории репозитория.
  • git status в системе Git показывает текущее состояние репозитория. Она отображает изменения, которые были добавлены в индекс (staging area) и готовы для коммита, а также изменения, которые ещё не были добавлены.
  • git commit в системе контроля версий Git используется для сохранения изменений в локальном репозитории. Она создаёт коммит — «снимок» состояния проекта в определённый момент времени. Коммит сохраняет все изменения в файлах, комментарий автора и ссылку на предыдущие версии.
  • git log в системе контроля версий Git используется для просмотра истории коммитов (фиксаций изменений) в репозитории. Она выводит список коммитов в обратном хронологическом порядке (самый свежий сверху).
  • git push — команда Git, которая отправляет локальные коммиты в удалённый репозиторий (например, на GitHub, GitLab или Bitbucket). Без неё изменения остаются только на вашем компьютере.
